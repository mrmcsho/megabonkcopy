# PrototypeArena

This directory is reserved for `PrototypeArena.umap`. It is intentionally source-only until the level is created and saved by Unreal Engine 5.8; binary Unreal assets must not be fabricated outside the editor.

Create an Empty Level named **PrototypeArena** here. The configured game mode constructs all Phase 1 test geometry when play begins, so the level itself should remain empty.
